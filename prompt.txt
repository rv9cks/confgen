создай скрипт на python :

 в начале скприпта считываем в массив  содержиоме файла source.txt  , при этом
 удаляем из строк все символы кроме цифр , строки нумеруем с 0 .
 открываем  config.ini , и основной цикл :
 - читаем из первой секции config.ini все параметры , читаем построчно из текущего каталога config.xml и заменяем в
   нем все шаблоны вида : 

 -- $name на значения переменных из текущей секции config.ini тоесть например
    $hostname из файла  config.xml заменяем на 66-CEMENT-ACC6614-VG1 
 -- $user_port_NN - , где NN - 2 цифры то тогда ищем в массиве полученном из
    source.txt строку с номером NN ( нумерация строк  0 )  и преобразуем ее к виду +7XXXXXXXXXX@ims.rt.ru где XXXXXXXXXX - последние
    10 цифр строки из source.txt после чего замещаем шаблон на полученное значение
 -- $number_port_NN - преобразуем его к виду +7XXXXXXXXXX где XXXXXXXXXX - последние
    10 цифр строки из строки с номером NN ( нумерация строк  0 )  source.txt после чего замещаем шаблон на полученное значение
 -- $passwd_port_NN - преобразуем к виду Rz_XXXXXXX$ где XXXXXXX -
    последние 7 цифр из строки строку с номером NN ( нумерация строк  0 )  полученной из source.txt
 -  полученные поле замены строки
    записываем в новый файл с именем hostname-generated-datetime.xml , где hostname - текущеее содержимое
    из config.ini , datetime - текущее время и дата.
 -  цикл повторяется с данными из следующей секции config.ini
